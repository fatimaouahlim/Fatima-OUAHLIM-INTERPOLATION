# Polynomial Interpolation – OUAHLIM FATIMA

Lagrange, Newton and Hermite interpolation of `e^x` and `1/(1+25x^2)` on [-1, 1],
with the Runge phenomenon shown for equally spaced points.

## Run

```bash
pip install numpy matplotlib
python interpolation.py
```
## Files

- `interpolation.py` – the code
- `images/` – hand calculations and graphs
